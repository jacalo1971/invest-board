# invest-board

Datos del Board de Inversiones de HTV Studio, publicado en https://htv.studio/invest

La carpeta `data/` se actualiza cada día hábil antes de la apertura y después del cierre del mercado (hora de Nueva York). Fuentes: Financial Modeling Prep y Alpha Vantage; análisis generado con Claude.

Información educativa; no es asesoría financiera ni recomendación de compra o venta.
